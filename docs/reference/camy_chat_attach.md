## camy chat attach

Re-join a paused or backgrounded turn (completes the fail-closed → approve → collect loop)

```
camy chat attach [flags]
```

### Options

```
      --chat string   chat id to re-join
  -h, --help          help for attach
      --turn string   specific turn id (the chat's live turn is attached; a mismatch is reported)
```
