# @camy/cli

Camy in your terminal. This package installs the `camy` command; the binary
for your platform arrives as an optional dependency, and nothing is fetched
at install time.

```bash
npm install -g @camy/cli
camy auth login
```

macOS and Linux, arm64 and x64. Documentation, releases, and the installer
live at [github.com/trycamy/cli](https://github.com/trycamy/cli).
